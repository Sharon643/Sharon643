##  Featured Projects

### 🔍 [EvoSearch](https://github.com/Sharon643/EvoSearch)
An agentic research assistant that plans queries, searches the web, scores sources for relevance, authority, and freshness, synthesizes evidence, self-corrects weak research, and validates its final answer against the sources.

**Stack:** Python · FastAPI · LangGraph · LangChain · Ollama · SearXNG · React · Docker

---

### 🤖 [Job Search Copilot](https://github.com/Sharon643/Job-search-copilot)
A RAG-powered career assistant that analyzes resumes, evaluates job fit, identifies skill gaps, improves ATS compatibility, and prepares candidates for interviews.

**Stack:** Python · LangChain · Gemini · ChromaDB · FastAPI · Streamlit

---

### ⚽ [World Cup Predictor](https://github.com/Sharon643/World-cup-predictor)
An end-to-end ML project that predicts international football match outcomes and simulates the 2026 FIFA World Cup using Elo ratings, XGBoost, and Monte Carlo simulation.

**Stack:** Python · Pandas · Scikit-learn · XGBoost
